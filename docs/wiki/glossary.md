# Glossary

Short definitions. Numbers and sources live on the linked pages.

| Term | Meaning | See |
|---|---|---|
| **Alphabet pack** | Set of stitch files, one per character, per size, per format; not an installable font | [lettering](lettering-and-fonts.md) |
| **All-caps font** | Embroidery font whose "lowercase" files are capitals/small caps of the same height, without descenders | [lettering](lettering-and-fonts.md) |
| **Appliqué** | Fabric piece sewn onto the base: placement line, tack-down, trim, cover stitch | [digitizing](digitizing-fundamentals.md) |
| **ART** | BERNINA's native object format; only BERNINA software writes it | [formats](file-formats.md) |
| **Auto-digitizing** | Software converting artwork or TTF text to stitches automatically; quality varies | [lettering](lettering-and-fonts.md) |
| **Backing** | Stabilizer under the fabric | [basics](machine-embroidery-basics.md) |
| **Bean stitch / triple run** | Running stitch sewn forward-back-forward for a bold line | [digitizing](digitizing-fundamentals.md) |
| **Bobbin** | Lower thread spool; locks the top thread | [basics](machine-embroidery-basics.md) |
| **BX** | Embrilliance keyboard-font format | [lettering](lettering-and-fonts.md) |
| **Color change / stop** | Command that stops the machine (single-needle) or switches needle (multi-needle) | [digitizing](digitizing-fundamentals.md) |
| **Color sheet / worksheet** | Designer's PDF with size, stitch count and thread sequence | [workflows](customer-workflows.md) |
| **Compensation (pull/push)** | Widening/shortening shapes to offset fabric distortion; typical 0.2–0.4 mm | [digitizing](digitizing-fundamentals.md) |
| **Cover stitch** | Final satin/blanket stitch hiding the raw edge of appliqué | [digitizing](digitizing-fundamentals.md) |
| **Cut-away** | Stabilizer that stays in the garment; for knits | [basics](machine-embroidery-basics.md) |
| **Density** | Distance between stitch lines (mm); smaller = denser | [digitizing](digitizing-fundamentals.md) |
| **Descender** | Part of a letter below the baseline (g, j, p, q, y) | [lettering](lettering-and-fonts.md) |
| **Digitizing** | Creating embroidery objects/stitches from artwork | [digitizing](digitizing-fundamentals.md) |
| **DST** | Tajima stitch format; no colors; 12.1 mm max per record | [formats](file-formats.md) |
| **Edge run / contour underlay** | Underlay just inside an object's edge | [digitizing](digitizing-fundamentals.md) |
| **EMB** | Wilcom/Hatch object (working) file | [formats](file-formats.md) |
| **Embroidery field / sewing field** | Area the machine can actually stitch with a given hoop | [basics](machine-embroidery-basics.md) |
| **EXP** | Melco/BERNINA stitch format; BERNINA adds INF + BMP | [formats](file-formats.md) |
| **Fill / tatami** | Rows of running stitches covering an area | [digitizing](digitizing-fundamentals.md) |
| **FSL (free-standing lace)** | Lace made only of thread on wash-away stabilizer; don't resize | [resizing](resizing-and-editing.md) |
| **HUS** | Older Husqvarna Viking compressed stitch format | [formats](file-formats.md) |
| **Hoop / frame** | Clamp holding fabric taut; named by nominal inches (4x4, 5x7) | [basics](machine-embroidery-basics.md) |
| **Hoop code** | JEF header field 0–4 naming a Janome hoop | [formats](file-formats.md) |
| **INF** | BERNINA thread-color companion file for EXP | [formats](file-formats.md) |
| **JEF / JEF+** | Janome stitch format / editable variant | [formats](file-formats.md) |
| **Jump** | Frame move with needle up | [digitizing](digitizing-fundamentals.md) |
| **Kerning / tracking** | Spacing between letter pairs / all letters | [lettering](lettering-and-fonts.md) |
| **Lock stitch (tie-in/tie-off)** | Tiny stitches securing thread at start/end (~0.7 mm) | [digitizing](digitizing-fundamentals.md) |
| **Monogram** | 1–3 initials arranged as a design | [lettering](lettering-and-fonts.md) |
| **Multi-needle** | Machine with 4–18 needles and automatic color changes | [basics](machine-embroidery-basics.md) |
| **Object file** | File storing shapes + parameters; stitches regenerated (EMB, ART) | [digitizing](digitizing-fundamentals.md) |
| **Pantograph / embroidery unit** | Mechanism moving the hoop in X/Y | [basics](machine-embroidery-basics.md) |
| **PEC** | Brother stitch block embedded in PES; palette indices + 48×38 thumbnails | [formats](file-formats.md) |
| **PES** | Brother/Baby Lock format; PES header + PEC block | [formats](file-formats.md) |
| **Placement line** | First appliqué step showing where fabric goes | [digitizing](digitizing-fundamentals.md) |
| **Puff (3D)** | Satin over foam; very dense, end caps | [digitizing](digitizing-fundamentals.md) |
| **Running stitch** | Single line of stitches, ~2–3 mm typical | [digitizing](digitizing-fundamentals.md) |
| **Satin** | Zigzag column stitch; width limit ~7–12 mm | [digitizing](digitizing-fundamentals.md) |
| **Sequencing / pathing** | Order of objects and travel between them | [digitizing](digitizing-fundamentals.md) |
| **SEW** | Legacy Janome/Elna/Kenmore format | [formats](file-formats.md) |
| **Short stitch** | Stitch under ~0.5–1 mm; thread-break risk | [digitizing](digitizing-fundamentals.md) |
| **spm** | Stitches per minute (machine speed) | [basics](machine-embroidery-basics.md) |
| **Stabilizer** | Material supporting fabric: cut-away, tear-away, wash-away | [basics](machine-embroidery-basics.md) |
| **Stitch file** | File of needle positions + commands (PES, DST, JEF...) | [formats](file-formats.md) |
| **Stitch processor / recalculation** | Resizing by regenerating stitches (Embrilliance 50–250%) | [resizing](resizing-and-editing.md) |
| **Tack-down** | Appliqué step fastening fabric before trimming | [digitizing](digitizing-fundamentals.md) |
| **Tear-away** | Stabilizer removed after stitching; for stable wovens | [basics](machine-embroidery-basics.md) |
| **Topping** | Wash-away film on top of pile fabrics | [basics](machine-embroidery-basics.md) |
| **Travel move** | Move between areas; in VP3 stored as a long stitch (> 12.1 mm) | [formats](file-formats.md) |
| **Trim** | Thread cut; DST encodes it as consecutive jumps | [formats](file-formats.md) |
| **TTF / OTF** | Computer outline fonts; need auto-digitizing to stitch | [lettering](lettering-and-fonts.md) |
| **Underlay** | Light stitching under top stitches (center run, edge run, zigzag, tatami) | [digitizing](digitizing-fundamentals.md) |
| **VIP** | Husqvarna Viking/Pfaff compressed format after HUS; no pystitch reader | [formats](file-formats.md) |
| **VP3** | Current Husqvarna Viking/Pfaff format; RGB colors; no jump command | [formats](file-formats.md) |
| **Wash-away** | Water-soluble stabilizer; FSL, sheers, toppings | [basics](machine-embroidery-basics.md) |
| **Weight (thread)** | Thickness number; higher = finer (40 wt standard, 60 wt fine) | [basics](machine-embroidery-basics.md) |
| **XXX** | Singer stitch format; 12.4 mm max per record | [formats](file-formats.md) |
